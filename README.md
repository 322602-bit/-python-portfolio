# Student Test Score Predictor

## Problem
I am trying to predict a student’s test score based on how many hours they study and how many hours they sleep. This matters because study time and sleep affect performance in school.

## Solution
The project loads student data from a CSV file and trains an AI model using hours studied and hours slept. The model then predicts a test score for a student who studied 6 hours and slept 8 hours.

## Tools
- Python
- Pandas
- Scikit-learn (Linear Regression)
- "C:\Users\322602\Downloads\data.csv"


## Results – Output
The AI predicted a test score of 81 for a student who studied 6 hours and slept 8 hours.
